# Getting set up for the course


You do all the work for this course in **Google Colab**, in your web browser. There is nothing to install. Do Part 1 before Session 1: it takes 5 minutes.

Part 2, Python on your own laptop, is only for some projects later in the course. Skip it until your group has picked its project.

## Part 1: Colab (everyone, before Session 1)

You need a **Google account** (a personal Gmail is fine) and a **laptop** with an up-to-date browser. A phone won't do in class.

1. Open the [course notebooks page](https://github.com/niparis/gem-python-finance). It lists every notebook, session by session.
2. Next to **1a Time value of money**, click **Open in Colab**. Sign in with your Google account.
3. Click **File → Save a copy in Drive**, and work in your copy. If you work in the original, your work is lost when you close the tab.
4. Under "Catch the error 1", click the first grey code cell and press **Shift + Enter**. The first run takes a few seconds while Colab starts.

You're set when a number appears under the cell. It looks wrong: that's the first exercise in class, so don't fix it yet.

Colab has an AI assistant built in, **Gemini**. Some exercises are done with AI off. We'll show you how in class.

**Stuck on a step?** Paste this into any AI chat (ChatGPT, Claude or Gemini; the free versions are fine). Add a screenshot if you can.

```
I'm a finance student and I've never coded. For my course I need to open a Jupyter notebook in Google Colab from a link, save my own copy in Google Drive, and run the first code cell. Guide me one step at a time, and ask me whatever you need to know about my computer.
```

## Part 2: Python on your laptop (only if your project needs it)

Some projects in Sessions 5-10 end with a small web app built with **Streamlit**, and Streamlit doesn't run in Colab. Only those groups need Python on their laptop. Wait until your group has picked its project: we'll tell you if you need this.

Install **Python 3.14** and **uv**, the Python package manager. Pick your way:

| Your situation | What to do |
| --- | --- |
| You have a **ChatGPT account** (the free one is fine) | **Way A:** the Codex app installs it for you |
| Anything else | **Way B:** you install it, with an AI chat as your guide |

### Way A: an AI app installs it

Use the **Codex** app with your ChatGPT account. It works on your computer, which an ordinary chat in your browser can't do. If you pay for Claude, **Claude Code** works too. Start a new session and paste:

```
I'm a finance student with no technical background. Please install Python 3.14 and uv, the Python package manager, on this laptop for my course.
Before you change anything, tell me in plain language what you found and what you plan to do, and explain each step in one simple sentence as you go.
When you're done, show me that Python and uv work.
```

While it works:

- It asks for permission before it does things. Read its one-line explanation. If it's about installing Python, approve it.
- If your computer asks for your password, type it **only into your computer's own window**, never into the chat.
- If it wants to delete files or turn off security settings, click **Deny** and ask your instructor.

### Way B: you install it, with an AI chat as your guide

Paste this into any AI chat (the free versions are fine):

```
I'm a finance student and I've never used a terminal. Guide me to install Python 3.14 and uv, the Python package manager, on my laptop. Go one step at a time, tell me what I should see, and wait until I say "done" before the next step. At the end, help me check that Python and uv work.
```

Type passwords only into your computer's own windows, never into the chat.

## If you get stuck

- Send the AI a screenshot of what you see and ask: "What do I do now?"
- The installer asks for an administrator password you don't have: you're probably on a school or work laptop. Ask your IT team, or use a personal laptop.
- Still stuck? Email your instructor with a screenshot, whether you have Windows or a Mac, and which part you were on (Part 1, way A or way B).
